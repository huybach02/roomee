# LocalQueryEngine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a generic in-memory engine that searches, filters, sorts, and paginates cached entities into a metadata-aware `OfflinePage`.

**Architecture:** Keep query logic pure and independent of Hive: callers provide entities, query parameters, schema, and optional `CacheMetadata`. Split schema, filter descriptors, result page, search normalization, and execution engine into focused files under `lib/core/offline/query/`.

**Tech Stack:** Dart, Flutter test, `diacritic` package.

**Spec:** `docs/superpowers/specs/2026-11-01-local-query-engine-design.md`

## Global Constraints

- No Workspace/UI/BLoC/datasource integration in this phase.
- Query order is search → filter → sort → pagination; total is computed after search/filter.
- Sort input is comma-separated prioritized `field:asc|desc`; invalid/unwhitelisted criteria are ignored.
- Filter operators are exactly `equals`, `notEquals`, `contains`, `inList`, `greaterThan`, `lessThan`, `between`, `isNull`; per-field descriptor whitelists allowed operators.
- Direct filter values mean `equals`; explicit filters use `{operator, value}`; `isNull` needs no value; malformed/unwhitelisted filters are ignored.
- Search uses `diacritic` normalization identically for query and entity strings, plus trim/lowercase.
- Numeric ordering supports int/double cross-comparison via `num`; non-numeric values and null fields cause ordering filters to be ignored.
- Equality/list operations use Dart equality, including null. `between` is inclusive.
- `page` invalid/missing defaults to 1; `limit` invalid/missing defaults to 20; no max limit; page is not clamped to last page.
- Sort nulls last independent of direction; ties use `uniqueId` ascending, else stable input order.
- `OfflinePage.source` is local; metadata null means `isComplete == false` and `lastFetchedAt == null`; `totalPages` minimum 1.

## Review Focus

- Vietnamese normalization: `khu tro` matches `Khu trọ`, including uppercase and extra whitespace.
- Invalid page/limit and page beyond final page: safe defaults while retaining requested valid page.
- Filter value/operator shape and type mismatch: invalid filter does not exclude records.
- Multi-sort with nulls and equal values: criteria precedence, null-last behavior, and stable tie-break remain deterministic.
- Empty result and incomplete metadata: `total == 0`, `totalPages == 1`, local source, metadata fallback.
