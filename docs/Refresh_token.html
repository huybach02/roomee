    Bức tranh lớn

    Access token = vé xem phim có in giờ (15 phút). Refresh token = thẻ thành viên để đổi vé mới (7 ngày). Bảng refresh_tokens = sổ thẻ của quầy. Hết vé thì app tự cầm thẻ ra quầy đổi, bạn không phải đăng nhập lại.
